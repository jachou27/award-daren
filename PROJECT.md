# Hotel Award Data Platform

## Project Vision

Build a production-style data platform that collects Hyatt award availability and pricing data, validates and transforms the data, and makes it available for SQL analytics, dashboards, alerts, and an optional AI interface.

## Current Sprint

### Sprint 0 — Foundation and System Design

**Status:** In Progress

**Goal:** Define the project architecture, MVP scope, data model, repository structure, and local development environment.

## MVP Scope

The first version will focus exclusively on Hyatt hotels.

The platform will eventually capture:

- Hotel information
- Search date
- Check-in and check-out dates
- Award availability
- Points price
- Cash price
- Room type
- Currency
- Data source
- Pipeline run metadata

## Future Roadmap

- Additional Hyatt properties
- Award availability alerts
- Marriott, Hilton, and IHG support
- Cloud deployment
- AI-powered natural-language querying
